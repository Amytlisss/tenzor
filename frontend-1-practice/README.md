# BRAVO Barbershop — Страница «Дата и время»

Вёрстка страницы выбора даты и времени для сайта барбершопа BRAVO.
Страница является частью пользовательского сценария записи клиента: после выбора мастера и услуги клиент переходит к этому экрану, чтобы указать удобную дату и время визита.

## Запуск проекта

1. Откройте файл `index.html` двойным кликом — страница откроется в браузере.
2. Либо используйте расширение Live Server в VS Code: нажмите правой кнопкой на `index.html` и выберите «Open with Live Server».

## Реализованные элементы

- Шапка сайта с логотипом и навигацией
- Прогресс-бар (шаг 4 из 5 — активный)
- Календарь на октябрь 2024 с навигацией по месяцам
- Кнопки навигации: «Назад к услугам» и «Продолжить»
- Подвал с контактами и адресом

## Технологии

- HTML5 (семантическая разметка)
- CSS3 (Flexbox и Grid)
- БЭМ-подобное именование классов

## Чек-лист задания

- Размеры, цвета, шрифты и положение элементов соответствуют макету
- Вёрстка семантическая — использованы теги `header`, `main`, `footer`
- Стили вынесены в отдельный файл `styles.css`, инлайн-стилей нет
- Использованы Flexbox и Grid для позиционирования
- У HTML-тегов есть классы, для них прописаны стили
- У активных элементов есть визуальная реакция на наведение (`:hover`)
- На кликабельных элементах установлен `cursor: pointer`
