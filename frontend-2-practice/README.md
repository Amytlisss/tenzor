# BRAVO Barbershop — Страница «Дата и время» (Задание 2. JavaScript)

Интерактивная вёрстка страницы выбора даты и времени для сайта барбершопа BRAVO.  
Страница является частью пользовательского сценария записи клиента. Реализована полная логика выбора даты, динамическая подгрузка временных слотов и валидация на чистом (нативном) JavaScript.
